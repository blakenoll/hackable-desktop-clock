What you need

Two parts and seven wires.

  • A

    ESP32-C3 SuperMini

    4 MB flash, USB built in. Other ESP32-C3 boards should work with the same pins.

  • B

    GC9A01 round display

    The common 1.28″ 240×240 SPI module.

  • C

    USB data cable and jumper wires

    Charge-only cables won't show up as a port.

Install guide

Three steps to a running clock.

01

Connect

Wire the display as shown above. The firmware assumes that exact pinout.

Plug the board into your computer with a USB data cable. No driver is needed: the chip has USB built in.

02

Flash

Click Flash and pick your clock in the browser's port list. It's called USB JTAG/serial debug unit, and is usually the only entry.

Progress shows in a panel on the right. It takes about a minute.

Open this page in desktop Chrome, Edge or Opera to flash.

Can't connect?

Auto-reset is sometimes unreliable. Unplug USB, hold BOOT, plug in while holding, keep holding for a few seconds, then click Flash.

Clock not listed? Try another cable. On Linux your user needs access to the port (usually the dialout group, then log out and back in).

Updating? Your saved WiFi and settings are kept.

03

Set up

The clock starts a WiFi network named clk-setup-XXXX. The password is shown on the clock's screen. Join it and a setup page opens, where you choose your WiFi (2.4 GHz only), timezone and ZIP code for weather.

To re-enter setup later, hold BOOT for 3 seconds while the clock is running.

USB JTAG/serial debug unit (usbmodem1101)

Not there? Check that it's plugged into this computer with a USB data cable.

If the clock wasn't in the list:

  • Plug it into this computer with a cable that carries data. Charge-only cables don't show up.
  • Unplug it, hold BOOT, plug it back in while holding, and keep holding for a few seconds.
  • Your user needs access to serial ports: sudo usermod -aG dialout $USER, then log out and back in.
