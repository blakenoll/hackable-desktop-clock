Desktop Clock installer

Flash the ESP32-C3 + round GC9A01 clock firmware straight from your browser.

Your browser doesn't support Web Serial. Use desktop Chrome, Edge or Opera (not Firefox, Safari or mobile).
Web Serial isn't available in this browser.

Before you start

  1. Wire the display as shown in the README. The firmware assumes that exact pinout.
  2. Plug the board into your computer with a USB data cable.
  3. Click Install, pick the board's serial port and confirm.

Your saved WiFi and settings are kept when you update.

If it can't connect

Auto-reset is sometimes unreliable. Unplug USB, hold the BOOT button, plug in while holding, keep holding for a few seconds, then click Install and choose the port.

First-time setup

The clock starts a WiFi network named clk-setup-XXXX. The password is shown on the clock's screen. Join it and a setup page opens, where you choose your WiFi (2.4 GHz only), timezone and ZIP code for weather. To re-enter setup later, hold BOOT for 3 seconds while the clock is running.
