01

Before you start

  1. Wire the display as shown in the README. The firmware assumes that exact pinout.
  2. Plug the board into your computer with a USB data cable.
  3. Click Connect & install and, in the popup, pick the port named USB JTAG/serial debug unit (usbmodem… on Mac, COM… on Windows, ttyACM… on Linux). Ignore entries like Bluetooth-Incoming-Port, debug-console or wlan-debug.

Your saved WiFi and settings are kept when you update.

02

If it can't connect

Auto-reset is sometimes unreliable. Unplug USB, hold the BOOT button, plug in while holding, keep holding for a few seconds, then click Connect & install and choose the port.

No driver is needed: the clock's chip has USB built in. If the clock isn't listed, try another cable. On Linux your user must be allowed to use the port (usually the dialout group, then log out and back in).

03

First-time setup

The clock starts a WiFi network named clk-setup-XXXX. The password is shown on the clock's screen. Join it and a setup page opens, where you choose your WiFi (2.4 GHz only), timezone and ZIP code for weather.

To re-enter setup later, hold BOOT for 3 seconds while the clock is running.
